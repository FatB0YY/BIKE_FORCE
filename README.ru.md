# Bike Force

Клиент-серверный интернет-магазин велосипедов и снаряжения, построенный как многосервисное приложение: API на TypeScript поверх PostgreSQL, витрина с серверным рендерингом, отдельная админ-панель на React и nginx в роли обратного прокси — всё поднимается через Docker Compose.

## Архитектура

| Сервис | Роль |
| --- | --- |
| `server` | REST API на Node.js, Express и TypeScript, база — PostgreSQL |
| `ssr_v2` | Витрина магазина с серверным рендерингом главной страницы |
| `client_v2` | Админ-панель на React, RTK Query и TypeScript |
| `nginx` | Обратный прокси, распределяющий трафик между сервисами |
| `docs` | Диаграммы классов и активностей, документация по API |

Весь стек поднимается через `docker-compose.yml`.

## Инженерные решения

**База нормализована до третьей нормальной формы.** Схема проектировалась осознанно, а не наращивалась по ходу: таблицы декомпозированы до 3НФ, что убирает аномалии обновления и позволяет обеспечивать ссылочную целостность на уровне самой базы.

**Серверный рендеринг витрины.** Клиентская страница магазина рендерится на сервере, чтобы контент присутствовал в первоначальном HTML, — для магазина это напрямую влияет на индексацию поисковиками и время до первой отрисовки. Админ-панель, где ни то ни другое не важно, осталась клиентским React-приложением.

**Отдельный клиент для админки.** Разделение админ-панели и витрины разводит две принципиально разные задачи: витрина оптимизируется под анонимных посетителей и вес страницы, панель — под работу с CRUD авторизованным пользователем.

**Полная обработка ошибок.** Сценарии сбоев обработаны явно по всему API, а не отданы общему перехватчику, поэтому клиент получает предсказуемые и осмысленные ответы.

**Тесты, покрывающие сценарии использования.** В проекте есть набор тестов на основные пользовательские потоки.

## Стек

**Сервер** — Node.js, Express, TypeScript, PostgreSQL

**Инфраструктура** — Docker, Docker Compose, nginx

**Инструменты** — Prettier

## Запуск

Нужны Docker и Docker Compose.

    git clone https://github.com/FatB0YY/BIKE_FORCE.git
    cd BIKE_FORCE

Создайте файлы окружения с данными подключения к базе, `API_URL` и `JWT_SECRET`, затем поднимите стек:

    docker compose up --build
